Tempo · color system

Tempo palette

The app's semantic colors and typography, shown as individual roles and together in familiar screens. The screen previews use Tempo's 280 px window width and 460 px preferred height.

Theme reference. Both color schemes and type styles mirror ui/theme.slint. Tempo follows the system appearance; this switch lets you compare the palettes. On macOS the system font is SF Pro. Single- and multi-line fields share surface-input; icon controls share the secondary action ramp.

Typography

Tempo uses the platform system typeface. Body text stays at 15 px; the smallest supporting and caption roles are easier to read in the narrow app window.

Text, borders, and focus

The text steps move from primary ink to supporting copy to muted detail. Stronger borders outline controls; quieter borders separate content without becoming decorative stripes.

Changes from the previous palette

The same hue can serve more than one role when the meaning is compatible. The current theme uses one input role for both field types and one action ramp for secondary and icon controls.
